Bienvenue

Il n'y a rien à configurer : lance Rocket League et joue un match. L'application détecte tout — ton pseudo, tes victoires, ta série — et ouvre le tracker sur ton 2ᵉ écran.

Pseudo

Sert à savoir quelle équipe est la tienne pour compter victoires et défaites. Joue un match : les pseudos détectés apparaissent en suggestion.

Classé / occasionnel

Un match privé ne passe par aucune file d'attente : l'appli le reconnaît à ça et ne le compte pas. Coche si tu veux quand même les voir dans la session.
Les parties occasionnelles restent enregistrées dans le journal des matchs — elles réapparaissent dès que tu décoches cette option. Rien n'est supprimé.

Mode streamer (OBS)

Dans OBS : Sources → + → Navigateur, colle l'URL ci-dessus, et décoche « Arrêter la source lorsqu'elle est invisible » — sinon ta session repart de zéro à chaque changement de scène. Fond transparent automatique, aucun filtre de couleur à ajouter. Local uniquement : rien n'est exposé à internet.
L’overlay servi à OBS utilise les MÊMES blocs que le dashboard, avec sa propre disposition. Le compositeur ouvre une fenêtre où tu déplaces, redimensionnes, masques et règles chaque bloc sur un damier — ce qui est transparent le restera dans OBS. L’ancien bandeau compact reste servi sur /classic.
Ces deux réglages valent pour l’overlay servi à OBS. La bannière couvre toute la source pendant la célébration : coupe-la si ta source occupe tout l’écran. Aucun son ne sort jamais de l’overlay.

Cosmétiques
Swaps de fichiers cosmétiques préparés par la communauté.

Cette section modifie des fichiers du jeu

Seule fonction de l’application qui touche aux fichiers de Rocket League. Un swap remplace un fichier de TAGame\CookedPCConsole par un fichier préparé par la communauté. L’original est sauvegardé avant le premier remplacement et se restaure d’un clic. Rien n’est modifié pendant que le jeu tourne. Si une mise à jour ou une vérification des fichiers Steam/Epic remet les originaux, les swaps activés sont réappliqués automatiquement au prochain moment sûr. Modifier les fichiers du jeu relève des conditions d’utilisation de Rocket League : tu l’utilises sous ta propre responsabilité.

Gestion des cosmétiques indisponible : cette version de l’application ne l’inclut pas. Mets l’application à jour (section Application) pour l’utiliser.

Préréglage : Alpha Boost

Le paquet Alpha Boost (Boost_AlphaReward_SF.upk) est déjà dans les fichiers du jeu. Ce préréglage le copie par-dessus le boost que tu choisis : en jeu, ce boost prend l’apparence de l’Alpha Boost. Le son suit aussi : la fiche audio du paquet est renommée, l’événement Alpha restant, donc le boost sonne comme l’Alpha.

Choisis un boost que tu possèdes, non peint de préférence — Bubbles est le choix conseillé.
Préréglage actif. Il apparaît aussi dans la liste des swaps ci-dessous.

Swaps

Rocket League tourne : ferme le jeu d’abord. Rien n’est appliqué ni restauré tant qu’il est ouvert.
Aucun swap pour l’instant. Pour en ajouter : indique ci-dessous le fichier du jeu à remplacer (tape le début de son nom et choisis dans la liste), donne un libellé, puis sélectionne le fichier préparé qui le remplace.

Ajouter un swap

Le fichier de remplacement doit avoir la même extension que la cible : .upk, ou .bnk pour le son d’un boost. Il est copié à la place de l’original, sauvegardé une fois pour toutes au premier remplacement. Pour l’Alpha Boost, utilise un fichier .upk déjà préparé par la communauté (par exemple les presets partagés sur le Discord de Shift / Vibin’s Hub) : copier tel quel le paquet du jeu ne fonctionne pas, le boost devient transparent.
