Bienvenue

Il n'y a rien à configurer : lance Rocket League et joue un match. L'application détecte tout — ton pseudo, tes victoires, ta série — et ouvre le tracker sur ton 2ᵉ écran.

Recopie le MMR affiché dans le jeu (Paramètres → Interface → « Afficher le MMR », depuis la saison 22). Ensuite l'appli l'estime toute seule match après match (environ ±9) — reviens le corriger quand tu veux.
Attention aux matchs de placement (début de saison) : les gains y sont bien plus gros (souvent ±15 et dégressifs), l'estimation dérive forcément. Recopie ton MMR en jeu une fois tes placements terminés.

Apparence

Les couleurs s'appliquent partout : dashboard, mini-overlay et cette fenêtre. Et sur le dashboard, le bouton « Personnaliser » permet de déplacer, redimensionner et masquer chaque bloc.

Animations

Le test ouvre le dashboard et joue l'animation avec le style et le thème choisis.

Mini-overlay

Important : mets l'affichage de Rocket League en « Fenêtré sans bordure » (Paramètres → Vidéo). En « Plein écran » exclusif, Windows ne laisse aucune fenêtre passer devant le jeu — c'est pareil pour tous les overlays.

Alpha Boost

Le son est joué par l'application elle-même, à partir de la Stats API : aucun fichier du jeu n'est touché, rien d'injecté — compatible anti-triche, comme tout le reste. Adapté du projet communautaire trznx/Rocket_League-Alpha_Boost (MIT). Après la mise à jour, clique une fois sur « Réactiver la Stats API du jeu » ci-dessous pour une réactivité parfaite, puis redémarre Rocket League.

Mode streamer (OBS)

Dans OBS : Sources → + → Navigateur, colle l'URL (taille conseillée 860 × 220, fond transparent automatique). Le bandeau affiche ta session, la série, le score en direct — avec flash de but et bannière de fin de match. Les boutons « Tester victoire / défaite » ci-dessus l'animent aussi. Local uniquement : rien n'est exposé à internet.
